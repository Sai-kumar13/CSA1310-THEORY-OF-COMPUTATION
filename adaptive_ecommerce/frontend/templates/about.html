ℹ️ About the Project

Academic Capstone Project for the Subject: Theory of Computation (TOC)

Project Overview

Adaptive E-Commerce Search and Personalized Product Recommendation System

This project establishes a direct practical application of theoretical computer science concepts within a modern, production-grade e-commerce web platform. Unlike standard relational string matches, the system formalizes string recognition, token parsing, and query classification through Finite State Automata and formal language theory.

Theory of Computation (TOC) Formalisms

  • Deterministic Finite Automaton (DFA): Implemented as a 5-tuple \(M = (Q, \Sigma, \delta, q_0, F)\). The query string is processed symbol-by-symbol with deterministic transitions without backtracking. Used for pattern matching within product names and descriptions.
  • Non-Deterministic Finite Automaton (NFA): Models concurrent search token verification. Supports multiple possible next states and \(\epsilon\)-transitions, traversing candidate keyword branches simultaneously.
  • Regular Expressions & Kleene's Theorem: Proves equivalence between regular languages and finite automata. Regex patterns are applied for multi-word tokenization, partial keyword extraction, and structural validations.
  • State Transition Tables & Trace Logging: Every step of the computational transition function \(\delta(q, a) = q'\) is recorded in real time and visualized in the UI.
  • Context-Free Grammar (CFG) Parser: Formalized as \(G = (V_N, V_T, P, S)\) in Chomsky's hierarchy. Parses natural language product requirements via recursive descent, constructing concrete parse trees to extract database query constraints.

⚙️ The Three Core Modules

Module 1: Adaptive Product Search

Tokenizes search queries and executes DFA/NFA substring recognizers against product records. Supports case-insensitivity, partial matching, real-time suggestions, and instant feedback.

Module 2: Personalized Recommendation

Dynamically aggregates user interactions (search queries and product views). Real-time scoring updates category preference metrics and cross-recommends related catalog items.

Module 3: Ranking & Adaptive Filtering

Applies multi-attribute filtering (category, price range, brand, star rating) with custom multi-criteria weighted scoring:
Total = (Keyword × 3.0) + (Category × 2.5) + (Rating × 2.0) + (History × 1.5)

Module 4: Natural Language Search (CFG)

Interprets free-form natural language queries (e.g. "Show laptops under 50000") through a Context-Free Grammar parser, compiling them to structured database constraints.

Module 5: Comparison & Price Alert Center

Enables up to 4-product side-by-side technical comparisons with best-price and top-rated badges, persistent smart wishlist, and active database price-drop notifications.

Module 6: Search Intent Evolution (FSM)

Models user browsing as a Finite-State Machine across consecutive searches (EXPLORING ➔ SPEC_REFINING ➔ PRICE_COMPARING ➔ DECIDED) with proactive next-query recommendations.

Module 7: Typo Recovery & Edit Distance Transducer

Recovers zero-result searches via pure Python Levenshtein edit distance dynamic programming, generating "Did you mean?" corrections and approximate catalog matches.

Module 8: Adaptive Filter Advisor (Mealy Machine)

Context-dependent filter recommendation automaton that analyzes applied filter states and catalog distributions to suggest optimal category, brand, and specification chips.

Module 9: Diversity & Discovery Recommendations

Balances user exploitation ("More Like What You Like") with exploration ("Explore Something New") using category relationship transition graphs to introduce fresh product domains.

Technology Architecture

  • Frontend: HTML5, CSS3 (Modern Blue/White responsive design), Vanilla JavaScript ES6+ with Fetch API (Zero external UI dependencies).
  • Backend: Python 3 with Flask framework RESTful API.
  • Automata Implementation: Custom Python engine (backend/automata.py) implementing DFA, NFA, and Regex evaluators without simulated mockups.
  • Database: MySQL relational database storing categories, products, user activities, search history, and real-time preference vectors.
