🔬 Theory of Computation (TOC) Interactive Demonstration

Real-time execution of Deterministic Finite Automata (DFA), Non-Deterministic Finite Automata (NFA), Regular Expressions, and Pattern Matching algorithms.

Deterministic Finite Automaton (DFA) Processor

A DFA represents a formal 5-tuple \(M = (Q, \Sigma, \delta, q_0, F)\). Every state has exactly one transition for each symbol in the alphabet.

Non-Deterministic Finite Automaton (NFA) Processor

An NFA allows multiple next states from a single symbol as well as \(\epsilon\)-transitions: \(M = (Q, \Sigma, \delta, q_0, F)\) where \(\delta: Q \times (\Sigma \cup \{\epsilon\}) \to \mathcal{P}(Q)\). The machine accepts if at least one concurrent branch reaches an accepting state.

Regular Expression (Regex) Formal Pattern Matcher

According to Kleene's Theorem, regular languages are precisely those accepted by finite automata and described by regular expressions. Test tokenization, lookaheads, and character classes against text.

Live Catalog Automaton Verification

Shows how real user queries are decomposed into tokens, transformed into search DFAs and NFAs, and verified against all live products stored in the database.

Context-Free Grammar (CFG) Natural Language Search Engine

A Context-Free Grammar is a 4-tuple \(G = (V_N, V_T, P, S)\) that generates syntactic structures via non-terminal derivations. This module parses natural language queries into concrete parse trees and extracts database query constraints.

Search Intent Evolution — Finite-State Model

Models the user's changing search intent as a formal Finite-State Machine \(M = (Q, \Sigma, \delta, q_0, F)\). Consecutive queries act as input symbols that trigger state transitions: broadening, narrowing, specification refining, or price comparing.

Approximate Pattern Matching — Levenshtein Edit Distance Transducer

Demonstrates dynamic programming matrix computation for string edit distance (Insert, Delete, Substitute operations). Used for zero-result recovery, automatic spelling correction, and approximate catalog matching.

Adaptive Filter Selection — State-Based Mealy Machine

Models an adaptive filter advisor as a finite-state machine where state transitions occur when filters are applied or removed. The machine evaluates the current filter configuration and catalog constraints to emit the optimal next filter suggestions.
